Conseils pour une bonne photo
  • Tissu bien à plat, défroissé si possible : les plis marqués peuvent passer pour des taches.
  • Appareil au-dessus du centre, parallèle au tissu ; tout le tissu dans le cadre.
  • Lumière douce, sans reflet ni ombre nette.
  • Si la table ou le sol apparaît autour, utilise « Recadrer ».

CAMÉRA EXTERNE

Utiliser un téléphone ou une autre caméra

Fixe le téléphone sur un support au-dessus du tissu, puis pilote la prise de vue depuis l’ordinateur : tu vois l’image en direct ici et tu cliques « Figer l’image » au bon moment.

1. Connecter le téléphone à l’ordinateur

Android + Windows 11 (sans application à installer sur le PC)
  1. Sur le téléphone, installe ou mets à jour l’application Lien avec Windows (Android 9 ou plus récent).
  2. Sur le PC : Paramètres → Bluetooth et appareils → Appareils mobiles → Gérer les appareils, ajoute ton téléphone puis active « Utiliser comme caméra connectée ».
  3. Accepte la notification sur le téléphone. La caméra apparaît dans la liste ci-dessous sous le nom Windows Virtual Camera.
Android ou iPhone avec une application webcam (DroidCam, Iriun, Camo…)
  1. Installe l’application sur le téléphone et son logiciel compagnon sur le PC (même éditeur, site officiel).
  2. Mets le téléphone et le PC sur le même Wi-Fi, ou relie-les en USB pour une image plus stable.
  3. Lance l’application sur les deux appareils : le téléphone devient une webcam (« DroidCam Source », « Iriun Webcam », « Camo »…).
iPhone + Mac
  1. Avec macOS 13 ou plus récent et le même identifiant Apple, l’iPhone posé à proximité apparaît automatiquement comme caméra (Caméra de continuité).

2. Choisir la caméra

Si ton téléphone n’apparaît pas : vérifie l’étape 1, ferme les autres applications qui utilisent la caméra (Teams, Zoom…), puis actualise.

3. Réussir la photo

  • Téléphone fixe (trépied, support), objectif parallèle au tissu, au-dessus de son centre.
  • Tout le tissu dans le cadre, avec un peu de marge ; lumière diffuse, sans reflet ni ombre portée nette.
  • Clique « Figer l’image » sur l’ordinateur, puis « Recadrer (4 coins) » pour retirer le fond et corriger la perspective.
